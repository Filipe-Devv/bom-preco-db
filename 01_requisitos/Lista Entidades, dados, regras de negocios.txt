---Regras de Negócio--- (10)



RN01

Cadastro de cliente, obrigatoriamente necessitara de nome, cpf, email.

RNO2

O cadastro podera ser feito apenas uma vez pelo (chave unica) cliente com o nome, cpf, email.

RNO3

Preço do produto não pode ser menor que 0$

RNO4

A quantidade do produto não pode ser menor que 0

RNO5

O fornecedor devera definir apenas um preço para o seu produto, Ex:. Arroz 10$ em um local do fornecedor, e em outro local no mesmo supermercado arroz 15$.

RN06

Todos os nomes não podem ter menos de 2 caracteres

RNO7

A cada mes o sistema realizar um backup de todos o sistema.

RNO8

O sistema avisa quando o estoque estiver abaixo de 30 items.

RNO9 

Cada cliente tera um pedido com obrigatoriamente mais de 0 produtos dentro dele.

RN10

O sistema verifica a quantidade de produtos no estoque.



----Regras de Dados--- (10)

RD01 

O sistema devera armazenar da entidade produtos: nome,preço,quantidade,.

RDO2

O sistema devera armazenar da entidade cliente: Nome, Cpf, Contato, Cidade do fornecedor durante o cadastro.

RDO3

O sistema devera armazenar da entidade fornecedor: nome,produto,contato,cidade,Cpnj.

RDO4

O sistema devera dar baixa no estoque dos produtos dependendo da quantidade retirada.

RDO5
O sistema deve registrar cada venda com data, cliente e itens vendidos.

RD06 

O sistema deve armazenar a quantidade que possui no estoque.

RD07

O sistema armazena a entidade pedido:item do pedido, e assim salvando o pedido

RD08

O preço final da entidade item do produto deve ser somado pela quantidade de produtos inseridos.

RD09

O sistema armazena a data da entega dos produtos do fornecedor.

RD10

O sistema armazena a categoria do produto Ex:. Arroz ala B bloca D.
